# Exploratory Data Analysis & Data Cleaning Suite

This repository contains end-to-end Data Science workflows focusing on Exploratory Data Analysis (EDA), Data Cleaning, Feature Engineering, and Query Analysis across multiple real-world datasets.

---
Cover the following core areas:

1. Data Cleaning: Handle missing values, check for duplicate records, and ensure correct data types.

2. Univariate Analysis: Analyze the distribution of individual variables such as Applicant Income, Loan Amount, Credit History, and Education level.

3. Bivariate/Multivariate Analysis: Explore relationships between features (e.g., How does Credit History or Education impact Loan Status? Is there a correlation between Income and Loan Amount?).

4. Outlier Detection: Identify any anomalies or outliers in numerical attributes like income and loan amounts.

5. Visualizations: Use appropriate plots (e.g., Box plots, Bar charts, Histograms, and Heatmaps) to support your insights.
